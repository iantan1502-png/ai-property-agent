# Security Policy

## Reporting Security Issues

Please do not publicly disclose security vulnerabilities through GitHub issues.

If you discover a security issue, contact the maintainer privately so the issue can be investigated before public disclosure.

## Sensitive Information

This project must never contain:

- API keys
- WhatsApp or Meta access tokens
- Database credentials
- CRM credentials
- Customer personal information
- Production secrets
- Authentication tokens

Example configuration files should use placeholder values only.
